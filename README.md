# Smart Finance Planner 💰

A frontend-only personal finance planning web application built with HTML, CSS and JavaScript.

## Features

- Login / signup
- Salary and other income setup
- User-defined monthly savings
- Automatic financial plan
- Dashboard
- Income and expense transactions
- Search and filtering
- Category budgets
- Multiple savings goals
- Analytics and charts
- Smart financial suggestions
- Dark mode
- LocalStorage persistence
- Responsive design
- GitHub Pages compatible

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Chart.js CDN

## Run locally

Open `index.html` in a browser.

For the best experience, use VS Code Live Server or any static HTTP server.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the Pages URL.

## Important

This project uses browser LocalStorage. It is suitable for learning, portfolio and demonstration purposes. It is not production-grade authentication because passwords are stored locally and there is no secure backend.
